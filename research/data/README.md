# Research data

Dated, read-only snapshots the app and the agent cite. Nothing here is a live rate or an executable quote.

- `research-snapshot.json`: chains, protocols and yield pools, each row naming the source it came from (schema `harbor.research.v1`, parsed by `@harbor/data/research`).
- `research-history.json`: chain TVL series (schema `harbor.research.history.v1`).
