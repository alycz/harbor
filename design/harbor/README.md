# Harbor design

- `tokens.css`: every color, type, spacing, radius and motion token, as `--harbor-*` custom properties. `packages/ui` maps them onto the shadcn variables.
- `assets/harbor-symbol.svg`: the mark, a breakwater arc around a beacon above the waterline.
- `assets/harbor-lockup.svg`: the mark with the wordmark.

Type is Geist and Geist Mono, loaded from `@fontsource` in the web app. Harbor is dark only.
- `assets/harbor-symbol-light.svg`: the mark in the text color, for use on accent backgrounds.
